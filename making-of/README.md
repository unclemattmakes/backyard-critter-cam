# Behind the Glass — the making-of page

A static, public, **camera-free** companion to the live rig: a chaptered walk-through of how the
backyard critter cam works, with eight interactive demos built on a **frozen slice of the real
database**. No GPU, no server logic, no live feed — just HTML/CSS/vanilla JS over baked JSON.

## Build the dataset

The page reads `data/*.json` + `media/` produced by the exporter (run from the project root):

```bash
python makingof_export.py            # bakes everything from backyard.db (DB + numpy + opencv + PIL)
python makingof_export.py --score    # also runs the open_clip non-animal gate for the decoy demo
```

`--score` loads the same `open_clip` model the live rig uses to compute the gate's per-crop
`p(not animal)` and the two separation distributions in the decoy bench. Without it the decoy demo
still works on the stored BioCLIP verdicts; the threshold strip is just omitted.

Privacy: the exporter only ever exports `detection_class='animal'` crops and drops a name denylist
(person labels, non-critter labels). That filter reads the LABEL, so a person the detector boxed as
an animal and BioCLIP then named a species will slip past it — for those there's
`PRIVACY_DENY_IDS` in `makingof_export.py`, a list of detection ids refused outright. Look at the
exported crops before you publish and add anything that shouldn't be public. The only wide frames
are pulled from behaviour clips, which are yard-only by construction.

## View it

Serve this folder statically (it uses `fetch`, so `file://` won't work):

```bash
python -m http.server 8011 --directory making-of
# then open http://localhost:8011
```

## Layout

```
making-of/
  index.html        chapters 00–11 + the eight demo mounts
  makingof.css       the field-journal skin (lifted from ../dashboard.css)
  makingof.js        boot: loads data, fills meta, mounts demos, nav + reveal
  insights.html      "Twenty Nights" — the companion field report: the season's
  insights.css       findings as one designed page (arrival clock, cast, similarity
  insights.js        ladder, the gate, day/night trust), computed live from data/*.json
  demos/             one file per demo, each registers against window.MakingOf
    pipeline.js      01 · scrub a real capture through the pipeline
    glass.js         02 · what shooting through the glass door does to night crops
    decoy.js         03 · the decoy bench (BioCLIP can't say "no"; the gate can)
    appearance.js    04 · 2-D map of real MegaDescriptor embeddings
    copresence.js    05 · two raccoons in one frame — the co-presence badge
    reid_game.js     06 · guess against the model + the un-blend finale
    gait.js          07 · motion tracks: how each individual moves
    twoaxis.js       08 · appearance × behaviour, and the disagreement
  data/, media/      generated by makingof_export.py (regenerate, don't hand-edit)
```

## Deploying

**This repo already deploys it.** Every push touching `making-of/**` republishes the site via
`.github/workflows/pages.yml`; the live copy is
**<https://unclemattmakes.github.io/backyard-critter-cam/>**. The rig also serves it on the LAN
at `/making-of/` (a static route in `web.py`), so household visitors get the explainer without
the public URL.

Running your own fork? It's fully static — the same folder drops onto GitHub Pages, Netlify, or
any static host. `data/` and `media/` are generated artifacts; commit them if you want the host
to serve the frozen slice as-is.
