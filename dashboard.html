Instrument Panel

Adjust the camera in real time. If the picture is soft, try toggling Autofocus. Controls your camera can’t change are shown locked.

This is a networked camera — its exposure, focus and white balance are set on the camera itself (its own app or web page), not here.

Ignored Spots

Fixed scenery the detector keeps mistaking for an animal — a dark gap in a wall, a grill cover. Drag a box over the spot below and the rig will disregard detections that sit on it. An animal walking through is still kept.

No snapshot right now (is this camera running?) — existing spots are listed below and can still be removed.

Cameras

The cameras this rig watches. Add a USB camera by its index, or a networked one by its address — The Backyard Critter Cam speaks RTSP and MJPEG-over-HTTP directly, so no extra software is needed on the camera.

New camera

Letters, digits, _ and - only. This is stamped on every photo, visit and clip folder from this camera, so it cannot be changed later — name it for where the camera will actually point.

Run python backyard_cam.py --list-cameras on the rig to find it. The built-in webcam is usually 0.

Most dedicated IP cameras speak RTSP. A Raspberry Pi, an ESP32 or a phone running a streaming app usually serves MJPEG over HTTP instead — if the stream plays in a browser tab, it is HTTP, not RTSP.

Advanced

Motion area is in pixels of the full frame, so it scales with resolution — a value copied from a 1080p camera is nine times too strict on a 640×360 one, and the camera simply never triggers. Leave blank to inherit, or use the number tools/camprobe.py suggests.

Move this rig

Pack everything this rig has recorded — database, photos, clips, reference portraits, labels, config — into one folder, ready for python migrate.py restore on the new machine. Same format as the weekly backup, and append-only: run it again and only what’s new is added.

Packing writes this rig’s whole archive to a folder of your choosing, so like a camera password it can only be started at the rig itself — open this dashboard on the rig (http://127.0.0.1:8000) and start it there.

A path on this rig’s machine. Packing is safe while the rig is recording; the panel will remind you about the quick second pass.

Skips the ~1.3 GB model-weights mirror; the new machine re-downloads them instead.
